# 现代化 Web TodoList 应用

一个使用 Go 语言开发的现代化 Web 版 TodoList 应用，具有美观的用户界面和完整的功能。

## ✨ 功能特性

- 📱 **现代化界面**: 采用现代化设计风格，支持深色/浅色主题切换
- ⚡ **响应式设计**: 完美适配桌面端和移动端
- 🔧 **完整的CRUD操作**: 创建、读取、更新、删除待办事项
- 🏷️ **任务筛选**: 支持查看全部、进行中、已完成任务
- 📝 **任务详情**: 支持任务标题和详细描述
- ⏰ **时间记录**: 自动记录创建和更新时间
- 🎯 **任务统计**: 实时显示任务数量统计
- ⌨️ **键盘快捷键**: 支持 Ctrl+Enter 快速提交
- 🔄 **批量操作**: 一键清除所有已完成任务
- 💾 **内存存储**: 数据存储在内存中（重启后重置）

## 🚀 快速开始

### 前置要求

- Go 1.21 或更高版本
- 现代浏览器

### 安装和运行

1. **克隆或下载项目**
   ```bash
   # 如果在现有项目中，todolist 目录已经存在
   cd todolist
   ```

2. **启动应用**
   ```bash
   # 使用启动脚本（推荐）
   ./start.sh
   
   # 或者手动启动
   go mod tidy
   go run cmd/main.go
   ```

3. **访问应用**
   
   打开浏览器访问: http://localhost:8080

## 📱 使用指南

### 基本操作

1. **添加任务**: 在输入框中输入任务标题，可选择添加详细描述
2. **标记完成**: 点击任务前的圆形复选框
3. **编辑任务**: 点击任务右侧的编辑按钮（铅笔图标）
4. **删除任务**: 点击任务右侧的删除按钮（垃圾桶图标）

### 筛选功能

- **全部**: 显示所有任务
- **进行中**: 只显示未完成的任务
- **已完成**: 只显示已完成的任务

### 快捷键

- **Ctrl+Enter** (或 Cmd+Enter): 快速提交表单
- **Escape**: 关闭编辑模态框

### 主题切换

点击右上角的月亮/太阳图标切换深色/浅色主题，设置会自动保存。

## 🔧 开发说明

### API 端点

- `GET /api/todos` - 获取所有待办事项
- `POST /api/todos` - 创建新的待办事项
- `GET /api/todos/{id}` - 获取指定待办事项
- `PUT /api/todos/{id}` - 更新待办事项
- `DELETE /api/todos/{id}` - 删除待办事项
- `PATCH /api/todos/{id}/toggle` - 切换完成状态

### 数据格式

```json
{
  "id": 1,
  "title": "任务标题",
  "description": "任务描述",
  "completed": false,
  "created_at": "2024-01-01T12:00:00Z",
  "updated_at": "2024-01-01T12:00:00Z"
}
```
